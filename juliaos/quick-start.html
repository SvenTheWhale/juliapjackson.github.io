Quick start guide

How to “boot” JuliaOS for your scenario in a few clear steps—no installation required.

Step‑by‑step

Start a new “game” with JuliaOS

  1. Name the puzzle. “We’re migrating X,” “We keep breaking Y,” or “No one agrees on Z.”
  2. Expose the constraints. Time, risk tolerance, politics, regulations—JuliaOS runs best on real constraints.
  3. Load the pieces. Systems, teams, data, vendors, customers—anything that can move or be affected.
  4. Walk a real scenario. Choose a concrete event (an order, an outage, a release) and trace it end‑to‑end.
  5. Capture the pattern. Turn what we discover into diagrams, narratives, and test cases your teams can reuse.
Config snippet

JuliaOS as a configuration file

# Minimal configuration to engage JuliaOS
juliaOS: {
  mode: "analysis+stabilization",
  inputs: ["systems", "people", "constraints"],
  requires_polish: false,
  outputs: ["maps", "narratives", "decision_paths"],
  tone: "calm, precise, ego-free",
  expansions_enabled: ["migration_lab", "incident_codex"]
}

# To start a session, set:
juliaOS.session.puzzle = "Describe the system or problem in one honest sentence."
